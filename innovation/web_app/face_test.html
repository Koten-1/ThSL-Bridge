Thresholds

The CSV holds numbers only (brow scores and head angles), no images or video. Question cue is any marked brow (raised or furrowed) and negative is a head shake. Both are placeholders until the club confirms which movements ThSL actually uses.
To run it: keep face_test.html and face_tone.js in the same folder, then double-click face_test.html (Chrome or Edge) and allow the camera. No server or install needed. If the camera prompt never appears, open the folder in VS Code and use the Live Server extension instead.
